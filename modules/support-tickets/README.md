# Support Tickets / Техническая поддержка

- Русская документация: [`docs/README.ru.md`](docs/README.ru.md)
- English documentation: [`docs/README.en.md`](docs/README.en.md)

Bundled version: **1.7.0** for KaevCMS **0.45.1+**. Usage and text limits are configured by Owner. Closed unprotected tickets can be deleted individually by Owner, while retention cleanup handles old closed tickets in batches.

Встроенная версия: **1.7.0** для KaevCMS **0.45.1+**. Лимиты настраиваются владельцем. Закрытые незащищённые обращения владелец может удалять вручную, а retention-очистка удаляет старые закрытые обращения пакетами.

The bundled 512×512 WebP module artwork is stored at `assets/module.webp` and is discovered automatically by KaevCMS.

Комплектное изображение модуля WebP 512×512 хранится по пути `assets/module.webp` и автоматически обнаруживается KaevCMS.
