# Форум

Модуль `forum` — отдельный форум для пользователей KaevCMS.

## Установка

Владелец включает модуль в **Админка → Модули**. После включения форум доступен по адресу `/forum`.

Владелец KaevCMS автоматически получает доступ к управлению. Пользователи используют уже существующие аккаунты и публичные ники; собственных паролей форум не хранит.

## Статус текущей версии

Версия 0.1.0 содержит установочный каркас, публичную страницу и определение активного участника. Создание категорий и разделов будет добавлено далее, вместе с пользовательскими правами и сообщениями.

Выключение модуля закрывает его маршруты; данные при выключении не удаляются.
