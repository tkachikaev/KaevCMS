# Форум

Модуль `forum` добавляет в KaevCMS отдельный форум по адресу `/forum`.

## Включение и доступ

Владелец включает модуль в **Админка → Модули**. Включённый модуль появляется в навигации личного кабинета и открывается по адресу `/forum`.

Права управления форумом определяются по действующей административной сессии владельца KaevCMS. Обычные игроки используют уже существующие аккаунты и публичные ники. Дополнительной регистрации и собственных форумных паролей нет.

Если владелец одновременно вошёл в CMS как администратор и как игрок, на форуме можно выбрать нужного автора без выхода из системы.

## Доступные возможности

В версии 0.1.0 открывается главная страница форума; создание категорий и сообщений пока недоступно. Кнопка настроек видна только владельцу. Модуль не меняет права других разделов CMS.

Отключение модуля закрывает публичную страницу и административный маршрут, не удаляя сохранённые данные. Для работы модуля не нужна игровая база данных.
