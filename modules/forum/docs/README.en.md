# Forum

The `forum` module provides a separate discussion forum for KaevCMS.

## Installation

An Owner enables the module under **Administration → Modules**. Once enabled, the forum is available at `/forum`.

The CMS Owner automatically has forum management access. Players use their existing identities and public nicknames; the forum stores no additional passwords.

## Current status

Version 0.1.0 provides the installation skeleton, the forum landing page and request-scoped actor resolution. Categories, section permissions and posts are scheduled for later iterations.

Disabling the module closes its routes without deleting stored data.
