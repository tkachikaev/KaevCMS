# Live dev на тестовой виртуалке

Используйте отдельную тестовую установку и SSH-ключ пользователя, которому принадлежит код. Веб-сервер сохраняет чтение исходников и запись только в рабочие каталоги. Закрытый ключ хранится вне репозитория. Локальный SSH-псевдоним, например `kaevcms-test`, задаёт адрес, пользователя и ключ; скрипт не сохраняет пароли.

В папке исходников запустите:

```powershell
.\deployment\windows\live-dev.ps1
```

Первый пакет передаёт исходники приложения, затем процесс проверяет сохранения каждые две секунды. Обновите страницу тестового сайта, чтобы увидеть результат. Ctrl+C останавливает процесс в открытом терминале. Для одной синхронизации используйте `-Once`; также доступны `-SshHost`, `-RemoteRoot`, `-SourceRoot` и `-PollSeconds`.

Редактируемые файлы остаются в локальной папке проекта. Передача использует Windows OpenSSH и tar, а на виртуалке — PHP и rsync. Пакеты загружаются в закрытый временный каталог; перед применением проверяются все пути и синтаксис PHP. Сохраняются права владельца кода и группы веб-сервера, очищается только кэш скомпилированных Blade-шаблонов. Неудачный пакет выводит ошибку и повторяется. Удаляться могут только исходники, уже известные текущему процессу синхронизации.

`.env`, рабочие данные, загрузки, базы, миграции, lock-файлы зависимостей и метаданные релиза исключены. Изменения схемы БД и зависимостей применяются обычным проверенным обновлением. Правила версий модулей и тем сохраняются. После правки исходника редактора контента по-прежнему требуется `npm run build:editor`.

Завершённая правка проходит quality и browser gates, получает новую версию и отправляется в Git. Live dev не записывает установленную версию и не заменяет резервирование, миграции и восстановление обновлятора. Для фиксации готового релиза на виртуалке применяйте кумулятивный пакет штатным способом.

При смене владельца проекта повторно запускайте установщик VDS-агента: он должен назначить права всем исходникам, включая `themes` и `account-themes`. Установщик проверяет чтение manifests тем и от пользователя развёртывания, и от PHP-FPM.
