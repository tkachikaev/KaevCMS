# Модуль «Ежедневные награды»

Встроенный модуль `daily-rewards` добавляет месячные календари наград для игровых серверов KaevCMS. Модуль выключен после чистой установки и включается владельцем в разделе **Модули**.

## Как работает календарь

- Для каждого игрового сервера и календарного месяца создаётся отдельный календарь.
- CMS автоматически создаёт 28, 29, 30 или 31 день в зависимости от выбранного месяца.
- В один день можно добавить до 100 разных предметов: указывается ID предмета и количество.
- Новый календарь всегда создаётся выключенным. После заполнения дней его можно включить.
- Награду можно забрать только в соответствующий календарный день по часовому поясу из основных настроек KaevCMS. Пропущенные дни сгорают.
- Каждый доступный игровой аккаунт может получить награду одного дня только один раз.
- Предметы поступают в веб-инвентарь выбранного игрового сервера. После получения модальное окно показывает точные названия, иконки и количество предметов и предлагает открыть веб-инвентарь.

## Настройка администратора

1. Откройте **Модули** и включите **Daily Rewards**.
2. Откройте появившийся раздел **Ежедневные награды**.
3. Нажмите **Создать календарь**.
4. Выберите игровой сервер, год и месяц. Часовой пояс берётся автоматически из основных настроек KaevCMS.
5. Нажмите нужный день в визуальной сетке месяца. Откроется модальное окно с названиями, доступными иконками, ID и количеством предметов.
6. Включите день, добавьте или удалите строки `ID предмета` + `Количество`, затем закройте окно дня.
7. Для быстрого заполнения используйте **Копировать предыдущий день** и **Заполнить пустые дни этой наградой**, после чего сохраните и включите календарь.

Неизвестный ID предмета разрешено сохранить: это полезно для пользовательских предметов конкретной сборки. Если каталог предметов знает ID, рядом отображается локализованное название и доступная иконка.

## Защита истории

После первого получения:

- награды уже полученного дня нельзя изменить;
- журнал сохраняет снимок фактически выданных предметов;
- отключение календаря или всего модуля не удаляет историю и предметы веб-инвентаря.

Повторное нажатие защищено UUID запроса, транзакцией и уникальным ограничением базы данных.

## Права

- Владелец управляет календарями и состоянием модуля.
- Администратор с правом просмотра модулей может открывать календарь и журнал только для чтения.
- Игрок видит раздел только при включённом модуле и получает награды только для принадлежащих ему игровых аккаунтов подходящего LoginServer.

## Отключение

Отключение модуля убирает его страницы и пункты меню. Таблицы календарей, дней, предметов и журнала не удаляются. При повторном включении данные остаются на месте.
