# Голосование

Модуль позволяет настроить подключение к рейтингу KTreon. В этой версии доступны настройки и проверка API; голосование из кабинета и автоматическая выдача наград ещё недоступны. Наборы предметов можно настроить заранее.

1. Владелец включает Voting в **Панель управления → Модули**. При установке применяются миграции модуля.
2. В KTreon откройте **Мои проекты → Проект → Интеграция голосования**, выпустите ключ с правами `vote-intents:create` и `vote-events:read`. Скопируйте ID проекта и ключ (ключ показывается один раз).
3. В KaevCMS откройте **Голосование → Провайдеры → KTreon**. Введите ID проекта и API-ключ, сохраните настройки. Провайдер по умолчанию отключён.
4. Нажмите «Проверить подключение». Проверка читает не более одного события по HTTPS и не создаёт голос или награду. При изменении ключа или ID проекта проверьте подключение повторно.

Ключ хранится зашифрованным с использованием APP_KEY CMS. Не меняйте APP_KEY при обновлении или восстановлении. Пустое поле при сохранении сохраняет ключ текущего проекта; при смене ID старый ключ удаляется. Не публикуйте ключ, не передавайте его игрокам. При перевыпуске ключа в KTreon сохраните новый ключ в CMS.

Режим «Ждать подтверждения» безопаснее и включён по умолчанию. Настройка «Выдать сразу» несёт риск награждения голосов, которые впоследствии отклонят. В данной версии оба режима только сохраняются; награды не начисляются. Владелец и администратор управляют настройками, аудитор может их просматривать без доступа к ключу.

Если проверка не проходит, убедитесь в правильности ID, действительности ключа, публикации проекта и доступности ktreon.com по HTTPS с сервера CMS. При ограничении запросов повторите проверку позднее. Успешная проверка означает доступ к чтению событий, а не подтверждение работоспособности выдачи наград.

При обновлении до Voting 0.3.0 примените миграции модуля в разделе **Панель управления → Модули**. Доступ игрокам остаётся отключённым до появления выдачи наград. После подготовки первого приглашения смена подключённого проекта блокируется; перевыпуск ключа того же проекта разрешён.

В разделе **Голосование → Награды** выберите игровой сервер, укажите ID и количество предметов (до 100 разных предметов). Включение набора доступно для сервера, связанного с LoginServer. Сохраните настройки. Аудитор может просматривать их без редактирования. Вкладка «История» отображает обработанные голоса; синхронизация пока недоступна. Изменения наград применяются при первой обработке голоса, а не к уже сохранённым наборам.
