# ЮMoney — KaevCMS 0.50.12 / Donations 1.14.0

## Для администратора

1. На **публичном сайте с HTTPS** установите KaevCMS и включите Donations.
2. В **Donations → Валюты и цены** задайте цену одной монеты в рублях (RUB).
3. В **Donations → Платёжные системы → ЮMoney** укажите номер кошелька (он виден после сохранения) и секрет HTTP-уведомлений (он хранится зашифрованно и при повторном открытии обозначен звёздочками).
4. Скопируйте адрес уведомлений из админки в настройки HTTP-уведомлений своего кошелька ЮMoney.
5. Включите **«Принимать платежи через ЮMoney»** и сохраните. CMS автоматически показывает раздел пополнения в личном кабинете. Игрок выбирает количество монет, нажимает «Перейти к оплате» и попадает на форму ЮMoney.

Никаких отдельных переключателей test/live, выбора «тестового игрока» и редактирования `.env` для Donations нет. **Секрет** никогда не выводится обратно, а **номер кошелька** виден администратору. Для отключения новых оплат достаточно снять одну галочку; уже оплаченные заказы продолжат получать подписанные подтверждения.

## Почему нельзя проверить живую оплату на 127.0.0.1

Это локальный адрес: сервер ЮMoney не сможет направить на него уведомление. Для **настоящего** контрольного перевода и автоматического зачисления нужен публичный HTTPS-адрес и сайт с рабочей MySQL/MariaDB. На локальном компьютере проверяются экран, форма, подпись и расчёты автоматическими тестами, но не реальное поступление внешнего webhook. Эти требования проверяются только при попытке включения оплаты и отображаются понятным сообщением. Не выключайте проверки подписи ради локального перевода.

## Что остаётся безопасным

Общий Wallet не менялся. Сервер рассчитывает сумму заказа; ЮMoney сообщает о фактической сумме списания (`withdraw_amount`) и поступления (`amount`). Только подписанный HMAC-SHA256 webhook подходящего заказа может начислить монеты, один раз. Заказы, история и сохранённые подтверждения не теряются при остановке новых продаж. Секреты защищены ключом приложения, который следует сохранять при обновлениях. Настоящий перевод на личный кошелёк возможен только если условия ЮMoney допускают такую модель использования.
