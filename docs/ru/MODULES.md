# Модули

Модули являются доверенным PHP-кодом, а не изолированными плагинами. Только владелец может устанавливать, включать, подтверждать новую версию, применять миграции, отключать и удалять модуль. Администратор видит состояние модулей, редактор не имеет доступа к их управлению.

Каждый модуль использует строго проверяемый manifest, неизменяемую историю миграций, scoped routes, переводы, views и необязательные пункты навигации. Изменение или удаление уже применённой миграции блокирует runtime-загрузку до решения владельца. Неудачный пакет миграций откатывает только собственные новые изменения.

Встроенный модуль `promo-codes` добавляет одну или несколько привязанных к GameServer наград в основной веб-инвентарь. Отключение или удаление кода сохраняет историю активаций и наград.

Встроенный модуль `daily-rewards` добавляет отдельные месячные календари для игровых серверов. Награда текущего дня выдаётся один раз на подходящий игровой аккаунт через основной веб-инвентарь. См. [Ежедневные награды](DAILY_REWARDS.md).


Модуль может добавить необязательную обложку каталога по пути `assets/module.webp`. KaevCMS обнаруживает её автоматически, если это корректный WebP 512×512 размером не более 2 МБ; иначе в админке остаётся буквенная заглушка.

Promo Codes и Daily Rewards используют общее модальное окно результата для успеха и ошибки, включая иконки и количество выданных предметов.

Установка ZIP через браузер, автоматическое удалённое обновление модулей и sandbox пока намеренно отсутствуют.

Встроенный модуль `support-tickets` добавляет приватные обращения игроков. Владелец и администратор могут отвечать, аудитор работает только на чтение, а доступ редактора включается отдельно в настройках самого модуля. Документация находится в `modules/support-tickets/docs/README.ru.md`.
