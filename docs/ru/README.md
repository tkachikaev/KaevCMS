# Документация KaevCMS

KaevCMS — CMS на Laravel для серверов Lineage II. Здесь описаны публичный сайт, личный кабинет игрока, административная панель, подключения игровых баз, статистика, веб-инвентарь, кошелёк, модули, шаблоны, почта и обновления (обновление из панели с агентом VDS, пакет-мост для старых сайтов и загрузка пакета частями).
